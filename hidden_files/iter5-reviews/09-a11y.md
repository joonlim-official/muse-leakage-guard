## Findings

### P2 — medium

**1. Transcript subsection titles skip a heading level.**
*Evidence:* heading outline extracted from the rendered report:
`h1 Leakage validation` → six card `h2`s with `h3 Full evidence` →
then bare `h3 bin/leakage-audit` and `h3 bin/adversarial-run` with no
intervening `h2`. Their section label, "Raw transcripts", is a
`<summary>` — not a heading — so a screen-reader user traversing by
headings meets two orphan `h3`s that appear to belong to the last
card's "Full evidence" section.
*Recommendation:* make the section label a heading, e.g.
`<summary><h2>Raw transcripts</h2></summary>` (`<summary>` permits
heading content per the HTML spec), keeping the transcript titles as
`h3`s.
*WCAG:* 1.3.1 Info and Relationships.

### P3 — low

**2. `<h2>` nested inside `<button>` is invalid HTML.**
*Evidence:* generated markup is
`<button class="card-head">…<h2 class="callout" id="callout-A">…`
(also drives `aria-labelledby`). A `<button>`'s content model is
phrasing content only; `<h2>` is not phrasing content, so the document
is invalid. Browsers and modern SRs tolerate it, but older assistive
tech can misparse headings inside interactive controls.
*Recommendation:* restructure as `<h2><button class="card-head"
aria-expanded="false" aria-controls="detail-A">…</button></h2>`
(button inside heading — valid, keeps the heading outline and the
single-tab-stop disclosure pattern).
*WCAG:* 4.1.1 Parsing.

**3. Match-cell ✓/✗ glyphs are exposed to AT, doubling the announcement.**
*Evidence:* cell markup is
`<td class="cok">✓<span class="vh">matched</span></td>` — unlike the
evidence rows, the glyph is *not* `aria-hidden`, so a screen reader
announces roughly "check mark matched" (and "ballot x mismatched" on
failures) instead of just "matched".
*Recommendation:* add `aria-hidden="true"` to the glyph (or wrap it),
mirroring the evidence-row pattern. Keeps the hidden text label as
the single source of truth.
*WCAG:* 1.1.1 Non-text Content.

**4. Adversarial table lacks a `<caption>` and has jargon headers.**
*Evidence:* headers are `case / want / got / match` and there is no
`<caption>`; the only description is the preceding `.tiers` paragraph.
Row cells use `<td>` for the case name rather than `<th scope="row">`,
so with 36 rows a screen-reader user gets less orienting context when
moving vertically.
*Recommendation:* add `<caption>` (or `aria-label`) like
"Adversarial corpus results: expected vs actual exit code per case";
rename headers to "expected rc"/"actual rc"/"match"; use
`<th scope="row">` for the case-name column.
*WCAG:* 1.3.1 Info and Relationships; 2.4.6 Headings and Labels.

**5. `<footer>` is nested inside `<main>`.**
*Evidence:* the page-level footer (`Synthetic stub target … nothing
real was sent or disclosed.`) sits inside `<main class="wrap">`, so
it does not surface as a `contentinfo` landmark.
*Recommendation:* close `<main>` before `<footer>` so the disclaimer
is exposed as the page footer landmark.
*WCAG:* 1.3.1 Info and Relationships (landmark structure).

**6. Footer/muted text misses 4.5:1 in light mode.**
*Evidence (measured, light mode):* `footer` text `#6b7280` on
`#f6f7f9` = **4.34:1**; `.skip .mark` `#6b7280` on white = 4.34:1.
Dark mode passes (7.95:1). Everything else measured passes AA:
badge 7.13:1, subtotal 4.83:1, mode bars ≥9.3:1, hero text 14.14:1,
focus green on white 5.02:1. (The `.cok` glyph at 4.19:1 passes the
3:1 non-text criterion as a shape-distinct symbol, but darkening
`--ok`'s light-mode value to reach 4.5:1 would remove the ambiguity.)
*Recommendation:* darken `--mut` in the light theme (e.g. `#5b626d`
≈ 5.0:1) so all body/footer text meets AA; consider the same for
`--ok`.
*WCAG:* 1.4.3 Contrast (Minimum).

**7. No explicit `:focus-visible` style on the transcript `<summary>`.**
*Evidence:* `.card-head` has a custom focus outline, but
`summary` relies on the browser default, which is thin/absent on
some platforms.
*Recommendation:* extend the existing rule:
`.card-head:focus-visible, .transcript summary:focus-visible
{ outline: 2px solid var(--ok); outline-offset: 2px; }`.
*WCAG:* 2.4.7 Focus Visible.
